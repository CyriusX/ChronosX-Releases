# macOS Porting Roadmap: TimeTrack Desktop Agent

## Executive Summary

Port the existing Windows-only TimeTrack Desktop Agent to macOS while maintaining complete functional and visual parity. The solution must integrate with the existing backend without server-side changes.

**Current Architecture**: Two-process model (DesktopHost UI + AgentService background worker)
**Target Architecture**: macOS equivalent (MenuBar App + LaunchAgent daemon)

### 1.2 Technology Stack Decisions

| Component | Windows Stack | macOS Stack | Rationale |
|-----------|---------------|-------------|-----------|
| **UI Framework** | WinForms + WebView2 | AppKit + SwiftUI + WKWebView | Native macOS feel, SwiftUI for modern UI, AppKit for system integration |
| **Background Service** | Windows Service | LaunchAgent | Standard macOS daemon mechanism |
| **IPC Mechanism** | Named Pipes | Unix Domain Sockets | POSIX standard, high performance |
| **ORM** | Dapper | GRDB.swift | Type-safe, migratable, similar philosophy |
| **HTTP Client** | HttpClient | URLSession + Async/Await | Native, modern Swift concurrency |
| **JSON Serialization** | System.Text.Json | Codable | Native Swift support |
| **Logging** | Serilog | OSLog + swift-log | Native system logging |
| **Dependency Injection** | Microsoft.DI | SwiftDI / Factory | Similar patterns available |

## Phase 2: Platform-Specific Providers

### 2.1 ActiveWindowProvider (macOS Implementation)

**Windows Approach**: `SetWinEventHook` + `GetForegroundWindow` + `GetWindowThreadProcessId`

**macOS Approach**: NSWorkspace notifications + Accessibility API

```swift
// TimeTrackAgent/Providers/MacOSActiveWindowProvider.swift

import Cocoa
import ApplicationServices

final class MacOSActiveWindowProvider: IActiveWindowProvider {
    private var observer: Any?
    
    func startMonitoring() async throws {
        // 1. NSWorkspace notification for app activation
        NotificationCenter.default.addObserver(
            forName: NSWorkspace.didActivateApplicationNotification,
            object: nil,
            queue: .main
        ) { [weak self] notification in
            guard let app = notification.userInfo?[NSWorkspace.applicationUserInfoKey] 
                    as? NSRunningApplication else { return }
            Task { await self?.handleAppActivation(app) }
        }
        
        // 2. Accessibility observer for window changes within apps
        let options = [kAXObserverAdditionsNotification: kAXFocusedWindowChangedNotification]
        // ... setup AXObserver
    }
    
    func getActiveWindow() async -> ActiveWindowInfo {
        let app = NSWorkspace.shared.frontmostApplication
        let pid = app?.processIdentifier ?? 0
        
        // Get window title via Accessibility API
        let windowTitle = getWindowTitleViaAX(pid: pid)
        
        return ActiveWindowInfo(
            processId: Int(pid),
            processName: app?.localizedName ?? "Unknown",
            windowTitle: windowTitle,
            bundleIdentifier: app?.bundleIdentifier ?? "",
            timestamp: Date()
        )
    }
    
    private func getWindowTitleViaAX(pid: pid_t) -> String? {
        let app = AXUIElementCreateApplication(pid)
        var focusedWindow: CFTypeRef?
        AXUIElementCopyAttributeValue(app, kAXFocusedWindowAttribute, &focusedWindow)
        
        guard let window = focusedWindow else { return nil }
        var title: CFTypeRef?
        AXUIElementCopyAttributeValue(window as! AXUIElement, kAXTitleAttribute, &title)
        return title as? String
    }
}
```

**Permissions Required**:
- Accessibility permissions (AXUIElement)
- Screen Recording permissions (for window titles in some apps)

### 2.2 IdleDetector (macOS Implementation)

**Windows Approach**: `GetLastInputInfo` (user32.dll)

**macOS Approach**: `CGEventSourceSecondsSinceLastEventType`

```swift
// TimeTrackAgent/Providers/MacOSIdleDetector.swift

import CoreGraphics

final class MacOSIdleDetector: IIdleDetector {
    func getIdleTime() -> TimeInterval {
        let idleSeconds = CGEventSourceSecondsSinceLastEventType(
            .combinedSessionState,
            eventType: .null
        )
        return idleSeconds
    }
    
    func startMonitoring(threshold: TimeInterval) async {
        // Timer-based polling (same approach as Windows)
        while true {
            let idleTime = getIdleTime()
            if idleTime >= threshold {
                await notifyIdleState(duration: idleTime)
            }
            try? await Task.sleep(nanoseconds: 1_000_000_000) // 1 second
        }
    }
}
```

**Note**: macOS idle detection is more reliable than Windows - no P/Invoke needed.

### 2.3 MachineMetricsProvider (macOS Implementation)

**Windows Approach**: `GetSystemTimes`, `GlobalMemoryStatusEx`

**macOS Approach**: Mach kernel APIs + IOKit

```swift
// TimeTrackAgent/Providers/MacOSMachineMetricsProvider.swift

import Foundation
import IOKit.ps

final class MacOSMachineMetricsProvider: IMachineMetricsProvider {
    
    func getCpuUsage() async -> CpuMetrics {
        var cpuInfo: host_cpu_load_info = host_cpu_load_info()
        var count = mach_msg_type_number_t(MemoryLayout<host_cpu_load_info>.size / MemoryLayout<integer_t>.size)
        
        let result = withUnsafeMutablePointer(to: &cpuInfo) {
            $0.withMemoryRebound(to: integer_t.self, capacity: Int(count)) {
                host_statistics(mach_host_self(), HOST_CPU_LOAD_INFO, $0, &count)
            }
        }
        
        guard result == KERN_SUCCESS else { return CpuMetrics(user: 0, system: 0, idle: 0) }
        
        let total = Double(cpuInfo.cpu_ticks.0 + cpuInfo.cpu_ticks.1 + 
                          cpuInfo.cpu_ticks.2 + cpuInfo.cpu_ticks.3)
        return CpuMetrics(
            user: Double(cpuInfo.cpu_ticks.0) / total * 100,
            system: Double(cpuInfo.cpu_ticks.1) / total * 100,
            idle: Double(cpuInfo.cpu_ticks.2) / total * 100
        )
    }
    
    func getMemoryUsage() async -> MemoryMetrics {
        var stats = vm_statistics64()
        var count = mach_msg_type_number_t(MemoryLayout<vm_statistics64>.size / MemoryLayout<integer_t>.size)
        
        let result = withUnsafeMutablePointer(to: &stats) {
            $0.withMemoryRebound(to: integer_t.self, capacity: Int(count)) {
                host_statistics64(mach_host_self(), HOST_VM_INFO64, $0, &count)
            }
        }
        
        // Calculate used memory
        let pageSize = vm_kernel_page_size
        let used = UInt64(stats.active_count + stats.wire_count) * UInt64(pageSize)
        let free = UInt64(stats.free_count) * UInt64(pageSize)
        
        return MemoryMetrics(usedBytes: used, freeBytes: free)
    }
}
```

### 4.2 Token Management

Port JWT token storage and refresh:

```swift
// TimeTrackCore/Sources/Security/TokenStore.swift

import Security

actor KeychainTokenStore: ITokenStore {
    private let service = "com.timetrack.agent"
    
    func storeToken(_ token: AuthToken) throws {
        let query: [String: Any] = [
            kSecClass as String: kSecClassGenericPassword,
            kSecAttrService as String: service,
            kSecAttrAccount as String: "auth_token",
            kSecValueData as String: try JSONEncoder().encode(token)
        ]
        
        SecItemDelete(query as CFDictionary)
        let status = SecItemAdd(query as CFDictionary, nil)
        guard status == errSecSuccess else {
            throw TokenError.storageFailed
        }
    }
    
    func getToken() throws -> AuthToken? {
        let query: [String: Any] = [
            kSecClass as String: kSecClassGenericPassword,
            kSecAttrService as String: service,
            kSecAttrAccount as String: "auth_token",
            kSecReturnData as String: true
        ]
        
        var result: AnyObject?
        let status = SecItemCopyMatching(query as CFDictionary, &result)
        
        guard status == errSecSuccess, let data = result as? Data else { return nil }
        return try JSONDecoder().decode(AuthToken.self, from: data)
    }
}
```

### 7.2 Permissions Handling

```swift
// TimeTrackCore/Sources/Security/PermissionManager.swift

import Cocoa
import ApplicationServices

enum PermissionType {
    case accessibility
    case screenRecording
    case fullDiskAccess
}

class PermissionManager {
    static func checkAccessibility() -> Bool {
        let options = [kAXTrustedCheckOptionPrompt.takeUnretainedValue() as String: true]
        return AXIsProcessTrustedWithOptions(options as CFDictionary)
    }
    
    static func requestAccessibility() {
        let options = [kAXTrustedCheckOptionPrompt.takeUnretainedValue() as String: true]
        _ = AXIsProcessTrustedWithOptions(options as CFDictionary)
    }
    
    static func checkScreenRecording() -> Bool {
        // CGWindowListCopyWindowInfo requires screen recording permission
        let windows = CGWindowListCopyWindowInfo([.optionOnScreenOnly], kCGNullWindowID)
        return windows != nil && CFArrayGetCount(windows) > 0
    }
}
```
